## How it was reviewed

Every file was read in full by an audit agent, then re-audited by an independent adversarial verifier that diffed it against upstream; groups with findings went through a fix round and a second verification. Final verdict of that audit: playwright-cli: clean. That verdict missed that the examples wrote saved session state, page snapshots, screenshots and recordings outside the ignored `.playwright-cli/` folder, into the repo root. The PR review (2026-10-08) found this and a cut-off record. See "Fixes from the PR review (2026-10-08)" below.

## Fixes from the PR review (2026-10-08)

- `SKILL.md` L27 (Setup): new bullet: keep every file you create with playwright-cli under `.playwright-cli/`. Without a file name the CLI writes timestamped files there; a file name you pass resolves against the working directory (the repo root), so prefix it, e.g. `state-save .playwright-cli/auth.json`, `--filename=.playwright-cli/page.png`, `> .playwright-cli/before.yml`, `path: '.playwright-cli/video.webm'`. Why: the examples wrote saved state (cookies and tokens), page snapshots of CRM screens, screenshots and recordings into the repo root, outside the only ignore rule (`.playwright-cli/`), where a later commit could pick them up (review finding F4-4). The review's verifier checked the path handling in the `@playwright/cli` 0.1.22 source.
- `SKILL.md` L11 (Setup): appended that the `npx playwright test` commands in the references assume a Playwright workspace, which this repo does not have, so they run as `npx --no-install playwright test ...`, and that adding `@playwright/test` needs the owner's OK. Why: CLAUDE.md rules out a bare `npx <tool>` for a package missing from `node_modules` (without a TTY, npx downloads and runs the latest version), and the references keep upstream's bare form. Appended to the existing bullet so the line numbers in this record stay valid.
